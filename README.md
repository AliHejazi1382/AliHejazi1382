### 🚀 Featured Project

#### 🤖 ROS 2 Line Follower Robot

A camera-based line-following robot combining high-level robotics software with low-level real-time motor control.

**System architecture:**

`Raspberry Pi 3B+` → `ROS 2` → `STM32` → `Motor Driver` → `DC Motors`

Key components:

- **Raspberry Pi 3B+** for camera-based line detection and high-level motion commands
- **ROS 2 Jazzy** for the robotics software layer
- **STM32 NUCLEO-G474RE** for real-time motor control
- **AS5600 magnetic encoders** for wheel-speed feedback
- **L298N** motor driver
- Closed-loop wheel-speed measurement and control
